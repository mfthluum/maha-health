# 🩺 MAHA Health

**Your Digital Health Twin**

MAHA Health adalah aplikasi berbasis web yang membantu pengguna memantau kondisi kesehatannya melalui konsep **Digital Health Twin**.

Aplikasi ini memungkinkan pengguna memasukkan data kesehatan secara manual, kemudian sistem akan menganalisis kondisi tubuh menggunakan **Rule-Based Expert System** untuk menghasilkan **Health Score**, menampilkan karakter **Digital Twin**, serta memberikan rekomendasi gaya hidup sehat.

---

## 🚀 Fitur Utama

- 🔐 Login & Register
- 👤 Manajemen Profil Pengguna
- ❤️ Input Data Kesehatan
- 📊 Health Score
- 🧍 Digital Twin Character
- 📈 Riwayat Kesehatan
- 💡 Rekomendasi Kesehatan
- 📚 Edukasi Kesehatan

---

## 📋 Parameter Kesehatan

- ❤️ Heart Rate (BPM)
- 🩸 Blood Pressure
- 🫁 SpO₂
- 🌡 Body Temperature
- 💧 Water Intake
- 😴 Sleep Duration
- 🚶 Daily Steps
- ⚖ Body Mass Index (BMI)
- 😊 Mood

## 🎯 Konsep Aplikasi

1. Pengguna melakukan Login.
2. Pengguna memasukkan data kesehatan harian.
3. Sistem menghitung Health Score.
4. Sistem menampilkan Digital Twin sesuai kondisi tubuh.
5. Sistem memberikan rekomendasi kesehatan berdasarkan Rule-Based System.
